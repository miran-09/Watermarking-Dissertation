Project focus

The system focuses on generating watermarked images with an associated Image Signature, and verifying both watermark presence and image integrity after generation or image manipulation.

Research contribution

The proposed Prompt Embedding Predictor reduces ROBIN's iterative optimisation cost by estimating the optimised embedding in a single forward pass. The Image Signature layer additionally provides source and integrity information during verification.

Watermark Check

The watermark verification process checks an uploaded image for the ROBIN watermark. The recovered watermark pattern is compared with the expected pattern to determine whether the supported watermark is detectable.

Image Signature

Generated images also contain an Image Signature with information such as an image identifier, creator identifier, generation method and creation time. During verification, the signature is checked separately from the ROBIN watermark to determine whether the signed image content has been modified.

Foundation & acknowledgement

This project is built on the ROBIN watermarking framework: Huang, H., Wu, Y., & Wang, Q. (2024). ROBIN: Robust and Invisible Watermarks for Diffusion Models with Adversarial Optimization. NeurIPS 2024.

The original ROBIN research and publicly released codebase were used as the foundation for the implementation and experimental evaluation in this dissertation. The proposed Prompt Embedding Predictor is an extension developed in this project to reduce the computational cost of ROBIN's iterative prompt-embedding optimisation.
